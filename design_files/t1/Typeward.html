Philosophy

Abstract. We present Typeward, a local-first editor for LaTeX. Documents compile on the author’s machine, in seconds, without consulting anyone. We find this arrangement strictly preferable to the alternative; a proof is given below.

Definition 1 (Local-first). A document is local-first if it exists, in its entirety, as a plain file on hardware its author owns.

Theorem 4.2 (Privacy). Data that never leaves your machine cannot be leaked, mined, or sold from anyone else’s.

Proof. Immediate. The reader may verify by unplugging the router; Typeward will not notice.

Features

Each of the following is stated without proof. Download the editor; the proofs are left as an exercise for the reader.

+ Lemma 4.1

Incremental compile

Only what changed is re-typeset. The preview keeps pace with your cursor, not with your patience.

◇ Lemma 4.2

TikZ, live

Diagrams render as you type them — compass-and-straightedge geometry, with an undo stack.

✕ Lemma 4.3

Plain files

A project is a folder of .tex files on disk. Git approves. So will you, in ten years.

◇ Lemma 4.4

Entirely offline

Airplane mode is a supported configuration. So is a cabin with no Wi-Fi and a deadline.

+ Lemma 4.5

Native keybindings

Vim and Emacs emulation, both first-class. We decline to take sides.

✕ Lemma 4.6

One-keystroke export

PDF/A for the archive, a clean bundle for arXiv. ⌘E, and it is someone else’s problem.
