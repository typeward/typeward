# Visual editor (LaTeX, v3 — hidden-source WYSIWYG)

Moved from the root CLAUDE.md architecture seams; the root keeps a stub with the cross-module invariants.

- **Visual editor (LaTeX, v3 — hidden-source WYSIWYG)** (`src/lib/visual/`, 2026-07-19; design/STATUS.md row AC) — Source | Visual mode for `.tex` files, FREE. One real document: the verbatim source in the normal CM6 view; visual = a **StateField** of decorations + `atomicRanges` built from a full-document parse (`parse/` — hand-rolled evolved v1 scanner, NO lezer; `VisualDoc` tree with a **total-coverage contract**: every char is content | hidden-token | widget, dev-asserted — nothing falls through as raw markup, unknowns become chips/cards, lone braces become warn chips). **No-inline-reveal policy**: markup never renders in the page — not even at the cursor (the v1/v2 failure); source appears ONLY in the edit popover (`components/editor/visual/VisualPopover.tsx`, intent signal in `stores/visual-store.ts`, snapshot-guarded bounded Apply). Edits flow through a construct-aware keymap + a transactionFilter that rewrites user deletions to construct closure (wrapper pairs never orphan) and snaps selections out of atomic ranges (SyncTeX inverse included); typed TeX specials auto-escape; `$` opens the math popover. KaTeX math renders with `output:"html"` (MathML would put raw TeX back into the DOM). Incremental reparse splices at blank-line anchors with a failed-lookahead-safe restart window; its falsifier is the `updateDoc ≡ full reparse` property test — keep it passing when touching `parse/`. Budget aborts MAP the previous decorations (never clear — a cleared frame paints markup), then idle-reparse; repeated aborts → session-scoped visual-paused (`visual-store`). Mounted via compartment + dynamic import in `CodeMirror.tsx` (toggling preserves undo/LSP; NOT part of `editorKey`); vim/emacs keybindings force-suspend in visual; gutters/active-line off + wrap on are forced at the prop level in `text-shell.tsx`. Stock Mod+F is image-blind in visual mode — `search.ts` rebinds it to a visible-image search over `image.ts` (the shared kernel motion/search/clipboard must all consume). Mount/unmount dispatches ZERO doc changes (zero-corruption invariant, pinned by the freeze test). **Borrowed text** — anything a widget renders that lives OUTSIDE its own node span (the title block's `\title`/`\author`/`\date`, the preamble summary's `\documentclass`) — is resolved by `buildDecorations` from the whole `Text`, NEVER carried in a parser node field: the incremental splice reuses untouched nodes verbatim (`mapBlock`'s default arm), so a borrowed field goes stale whenever its source changes outside the rescanned region, and `\title` is legal in the body (the IEEE template does exactly that), which puts it past the `dFromA < oldBodyStart` full-reparse guard. The `updateDoc ≡ full reparse` property test is the falsifier — its 4th base doc exists for this. **Chips carry a human LABEL, never markup**: `COMMAND_LABELS` / `FILE_ARG_LABELS` first, else the bare control word with the backslash stripped, in `--font-sans` (mono is this codebase's signal for "source", so a mono control word reads as a leak). Same rule for `GhostWidget` placeholders — `GHOST_LABEL` keeps internal `StyleKind` identifiers off the page. **A command whose argument is prose must be a `StyleNode`, not a chip** (`INLINE_STYLES` / `WRAPPED_SECOND_ARG` in `scan-inline.ts`): the generic unknown-command arm swallows up to two `{..}` args into one atomic widget, which makes that prose invisible, unsearchable, and uneditable in place — the highest-severity failure mode in this module, worse than a bad label. `coverBlock`/`coverInlines`/`walkBlocks`/`walkInlines` carry `never` exhaustiveness guards; without them a node kind that misses a `cover*` arm silently reclassifies as content and renders RAW MARKUP as live text with `assertTotalCoverage` still green (see design/STATUS.md row AF).
