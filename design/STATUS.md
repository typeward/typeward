## Notes

- Settings persistence safe across upgrades: every new field uses
  `#[serde(default)]` on the Rust side. Users with older `settings.json`
  files load with the new defaults silently.
- Density default is **Cozy**; tablets get **Comfortable** auto-applied only
  on first run (handled in Phase E when the picker UI lands).
- Animations default **on**. OS-level `prefers-reduced-motion` still wins.
