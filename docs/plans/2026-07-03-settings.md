# Settings — expansion + theme restructure plan (2026-07-03, approved)

Three items, numbered to match the original request. Premise corrections found during design verification: the autosave debounce is frontend-side (`src/lib/autosave/index.ts`, ~500ms setTimeout; `autosave.rs` only writes snapshots), and fresh installs currently boot into Aurora — Rust `Settings::default().theme = "aurora"` overrides the frontend Daylight default when no settings.json exists (live bug, fixed by item 2).

## 1. Curated settings expansion (~12 new fields, 2 surfaced, 1 removed)

Rust `EditorSettings` adds (each `#[serde(default = ...)]`): `line_numbers` (true), `highlight_active_line` (true), `autocomplete` (true), `bracket_matching` (true), `auto_close_brackets` (true), `tab_size: u8` (2), `line_height: String` ("normal"), `autosave_delay_ms: u32` (500), `pdf_default_zoom: u16` (110), `pdf_invert_dark: bool` (false). **Remove the orphaned `spell_check`** (persisted but no UI writes it — the visible toggle drives `integrations.grammar.enabled`; serde ignores the stale key in old files). Mirror everything in `ipc.AppSettings.editor` + the TS `EditorSettings` + defaults; add `validate` clamps on the editor FIELDS entry (tabSize {2,4,8}; lineHeight validEnum compact/normal/relaxed = 1.5/1.65/1.85; autosaveDelayMs 200..5000; pdfDefaultZoom 50..300) per the load-boundary convention.

| Setting | Control | Consumer |
|---|---|---|
| Line numbers / active line / autocomplete / bracket matching / auto-close brackets | Switches | `CodeMirror.tsx` — new compartments; `bracketMatching()` (`@codemirror/language`) and `closeBrackets()` + keymap (`@codemirror/autocomplete`) are NEW extensions (not enabled today); the autocomplete toggle also gates the LSP completion source (`src/lib/lsp/cm6.ts`) |
| Tab size | Select 2/4/8 | `EditorState.tabSize` + `indentUnit` |
| Line height | Select compact/normal/relaxed | folded into the fontSize compartment (baseTheme hardcodes 1.65) |
| Autosave delay | Select 300/500/1000/2000 ms | `src/lib/autosave/index.ts` |
| PDF default zoom | Select 80–150% | seeds PdfViewer's zoom signal (single init point; the editor doc's item 9 consumes it) |
| Invert PDF on dark themes | Switch | CSS `filter: invert(0.92) hue-rotate(180deg)` on the canvas container when on and `isDarkTheme(theme())` |
| Default library view / sort | Selects | existing `workspace.defaultView` / `defaultSort`, newly surfaced in Settings (still settable from the Projects toolbar) |

Placement (no new nav sections): Editor → Editing card gains rows 1–7; the Compilation card gains Autosave delay; a new "PDF preview" card holds zoom + invert; Appearance → Accent card gains the gradient switch (item 3); Appearance → Workspace card gains the two library-default selects + updated Spaces/Tags hint copy. All editor toggles apply live via compartments — no remount; the LSP/grammar `editorKey` remount stays untouched. Deliberately not proposed: settings for features that don't exist (collab, notifications delivery, shortcut remapping).

## 2. Theme restructure — Basic vs Styled + two new themes

- Roster: `THEMES = ["light", "dark", "daylight", "lamplight", "aurora", "paper"]`; `THEME_ROSTER` gains `category: "basic" | "styled"` (light/dark = basic; the existing four = styled). Everything downstream (labels, LIGHT_THEMES, validEnum whitelist, Theme type) derives.
- Add-a-theme checklist per new theme (7 touchpoints, verified):
  1. `src/themes/themes/light.css` + `dark.css` — `[data-theme]` delta blocks (Aurora `:root` in tokens.css is the baseline; override deltas only, like paper.css).
  2. `@import` both in `src/styles.css`.
  3. theme-store `THEMES` tuple + `THEME_ROSTER` entries.
  4. `public/boot-theme.js` SPLASH rows — light `["#ffffff","#1a1d21","#6b7075","rgba(26,29,33,0.12)"]`, dark `["#1e1e1e","#d4d4d4","rgba(212,212,212,0.5)","rgba(255,255,255,0.08)"]`.
  5. `src-tauri/src/themes.rs` `BUILTIN_BASES` → 6 entries (custom themes may base on them).
  6. SettingsScreen `THEME_VIBE` entries (`#ffffff` / `#1e1e1e`, flat).
  7. `accents.css` — add `[data-theme="light"]` to the deepened light-theme compound selectors (dark uses the stock bright palettes); update the custom-theme fallback copy + `design/themes.md`.
- Token direction — **Light**: plain modern light editor — white bg; fg scale `#1a1d21` / `#4b5158` / `#697077` / `#8a9095`; hairline gray glass/control strokes; near-flat blue accent `#2563eb → #1d4ed8` (accent-fg white); GitHub-light-ish syntax (cmd `#0550ae`, env `#116329`, math `#953800`, comment `#6e7781`, attr `#0e7490`); status `#1a7f37` / `#9a6700` / `#cf222e`; **blob opacities all 0** (flat even with ambient lights on). **Dark**: neutral `#1e1e1e` — fg scale `#d4d4d4` / `#9da3a8` / `#8b9196` / `#6e7479`; card `#252526`-ish; accent `#5aa2f7 → #3d8bf2` with dark-ink accent-fg (Aurora convention); VS-Code-dark-ish syntax (cmd `#569cd6`, env `#4ec9b0`, math `#ce9178`, comment `#6a9955`, attr `#9cdcfe`); blob opacities 0.
- Picker: two labeled sections ("Basic", "Styled") filtering `THEMES` by category, reusing ThemeTile + grid-cols-4.
- **Default stays Daylight** (documented brand default; changing it churns splash/`tauri.conf.json`/docs); fix `Settings::default().theme` "aurora" → "daylight" in settings.rs — this also fixes the live fresh-install Aurora bug.

## 3. Accent gradient on/off

- ui-store: `accentGradient` signal (default true) + `document.documentElement.dataset.accentGradient = on|off` effect — the exact `data-ambient` pattern.
- `src/themes/utilities.css` appends `:root[data-accent-gradient="off"]` overrides: `--accent-text-1/2` → `var(--color-accent-1)` (flattens `.accent-text` via its own vars); solid `background: var(--color-accent-1)` for `.accent-grad`, `.accent-border`, `.caret`, `.side-active::before`; plus a dedicated off-rule for `.lift.accent-grad:hover` (it re-declares the gradient — flatten to an accent-fg wash over the solid color). `.glow-accent` stays (a glow, not a gradient).
- Persistence: `ipc.UiSettings.accentGradient` + Rust `accent_gradient` `#[serde(default = "default_true")]` + one settings-store `field()` entry.
- UI: a Switch in the Appearance → Accent card — "Blend both accent stops across buttons and highlights. Off uses the solid accent color." (Effect is subtle on Daylight — its gradient is already near-flat — and obvious on Aurora.)
